# ResearchPilot AI

ResearchPilot is a local PDF research assistant. Upload a PDF, ask questions about its contents, and get answers with page and text citations. The React interface talks to a FastAPI service; PDF text is indexed with a local sentence-transformer model, and answers are generated by Ollama.

## Requirements

- Python 3.10 or newer
- Node.js 20.19+ or 22.12+
- [Ollama](https://ollama.com/) with the configured chat model pulled locally

The first backend run downloads the `sentence-transformers/all-MiniLM-L6-v2` embedding model if it is not already cached. Use text-based PDFs; scanned image-only PDFs need OCR and currently produce no searchable text.

## Run locally

Open two terminals from the project folder.

### 1. Start the API

```powershell
cd backend
python -m venv .venv
.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
if (!(Test-Path .env)) { Copy-Item .env.example .env }
ollama pull qwen2.5:3b
python -m uvicorn app.main:app --reload
```

The API is at http://127.0.0.1:8000 and interactive API docs are at http://127.0.0.1:8000/docs. You can choose a different Ollama model or URL in `backend/.env` with `RESEARCHPILOT_OLLAMA_MODEL` and `RESEARCHPILOT_OLLAMA_BASE_URL`.

### 2. Start the web app

```powershell
cd frontend
npm install
npm run dev
```

Open the Vite URL printed in the terminal (normally http://localhost:5173). To point the frontend at another API address, set `VITE_API_BASE_URL` in `frontend/.env.local`.

## Use it

1. Upload a PDF of up to 10 MB.
2. Ask a question or choose one of the suggested prompts.
3. Review the cited evidence and confidence estimate alongside the answer.
4. Saved conversations are stored in `backend/researchpilot.db`; uploaded files are stored in `backend/uploads/`.

Research history and uploaded documents are local to this machine and are not encrypted by the app. Keep the backend bound to localhost unless you add authentication and appropriate network protections before exposing it to other users.

## API overview

- `POST /api/documents/upload` — validate and store a PDF.
- `GET /api/documents` — list stored PDFs.
- `POST /api/documents/{document_id}/answer` — answer a question about an uploaded PDF.
- `GET|POST /api/history` — list or save research sessions.
- `GET|DELETE /api/history/{session_id}` — retrieve or delete a session.
- `GET /health` and `GET /health/ollama` — service checks.
